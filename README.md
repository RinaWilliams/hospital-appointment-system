
# Hospital Appointment System
ASP.NET Core 8 Web API + MySQL + HTML/CSS/JavaScript.

## Run
1. Start MySQL (XAMPP) and run database/schema.sql.
2. Edit backend/HospitalApi/appsettings.json (password and JWT key).
3. Run the API in Visual Studio, then call POST /api/auth/seed-demo once.
4. Open the frontend with VS Code Live Server and set API_BASE in js/api.js.
